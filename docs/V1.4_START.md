# V1.4 模拟收益优化起点

V1.3.2 验收后开始只读基线分析，尚未改动战斗、Agent 或结算策略，也没有已验证的收益提升。

实际运行命令：

```powershell
.\.venv\Scripts\python.exe scripts/profit_baseline.py --database reports/v132-stress.sqlite3 --output reports/v14-profit-baseline.json
```

输入是隔离压测库，SQLite 只读打开，运行前后文件 SHA-256 相同。8 个独立运行全部成功；模拟金币 5134、碎片 182、材料 88，事件记录的消耗为真实零值。按已持久化运行耗时合计 93.178 秒计算，基线为 3305.944 模拟金币/分钟；该口径不含轮次间调度等待，压测墙钟时间为 100.475 秒，不能混用。

阶段指标及原始 run_id 在 JSON 中。没有样本或有效耗时的指标为 null，不补零。消耗单位 SIMULATED_SUPPLY_UNIT 与金币不同，不相减，不换算人民币。

下一阶段先重复多组相同条件实验，再比较寻路、战斗和拾取耗时；以模拟金币/分钟为主要指标，同时保留成功率和消耗约束。八轮短样本不能代表长期效率，优化前后必须使用一致口径并验证资源事件与结算一致。
