# V1.1：九星副本可追溯官网知识库

这是对 V1.0 的增量扩展。模拟器、Agent 决策/视觉/寻路/战斗算法与原测试文件未更改。复用 FastAPI、SQLite、Vue 控制台和原有实时日志。正式游戏公开资料仅供只读查询，没有变为自动动作。

## 页面

- 控制台：http://127.0.0.1:8000/#/console
- 九星副本知识库：http://127.0.0.1:8000/#/knowledge
- 九星副本流程：http://127.0.0.1:8000/#/flow
- 数据来源管理：http://127.0.0.1:8000/#/sources

采用 Vue Hash 导航，可直接刷新与打开链接，无需增加路由服务器。切换知识页面只改变浏览器展示，后台 Worker 不受影响。

## 初始化、采集与重复测试

```powershell
cd D:\myAI\moyu-v1\moyu-agent
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
# 只迁移知识库，不初始化 Worker，也不会标记当前运行中 Agent 为中断
.\.venv\Scripts\python.exe scripts/migrate_knowledge.py
# 真实抓取指定的三个公开官网页面
.\.venv\Scripts\python.exe scripts/collect_official.py
# 连续再采集，验证 SHA 去重；不会重复插入相同 HTML 的事实
.\.venv\Scripts\python.exe scripts/collect_official.py --report reports/official-repeat-collection.json
# 一键前端构建、pytest、隔离数据库、真实官网采集、两组 Playwright/API 验收
powershell -ExecutionPolicy Bypass -File .\test.ps1
```

可通过 CLI 的 `--db`、`--output` 和 `--report` 指定数据库、快照目录和统计文件。仅白名单中的三页允许采集；不爬其他副本、导航或私人接口。默认先读取 robots.txt，遵守 Disallow、Crawl-delay 与 Request-rate，每次请求至少间隔 1.5 秒。最多 3 次指数退避重试；403、404 和 robots 禁止不继续页面重试。不绕过访问限制，不使用登录凭据。

HTML 以原始字节保存在 SQLite BLOB 与 `data/official-snapshots/`，SHA-256 按原字节计算。根据 meta charset 解码，GB2312/GBK 使用兼容的 GB18030 解码。提取只读取包含副本名的正文表格，保留 CSS 元素路径，不从导航和相关推荐提取怪物或奖励。列结构异常时拒绝猜测，失败记录可在来源管理查看。

按来源 URL + HTML SHA 去重。正文或页头变化产生新快照，旧快照与事实不覆盖；同一 HTML 再采集只更新复见时间。提取器升级先在 extraction_revision 归档旧解析，再重新解析同一快照，保持事实 ID 与原 HTML 可追溯。数据冲突按规范值差异聚合，不自动决定胜者。跨历史页面的差异可能是版本变化，不等于某一来源错误。

## 数据迁移与来源隔离

迁移文件：`backend/migrations/002_official_knowledge.sql`。服务启动和迁移 CLI 都会幂等执行。它只新增表、索引、触发器及迁移登记，保留原 runs/logs/knowledge 与已有用户数据。上线前检查记录与 SQLite 备份存放在 `reports/v1.1-baseline/`。

新增实体：game_version、data_source、source_snapshot、dungeon_definition、dungeon_stage、dungeon_boss、dungeon_mechanic、dungeon_reward、game_item、fact_evidence、data_conflict、game_observation；另有 collection_attempt 和 extraction_revision。

知识实体统一声明 OFFICIAL_WEB / GAME_OBSERVATION / SIMULATOR / MANUAL_REVIEW 来源类型。首批结构化事实只写 OFFICIAL_WEB；观察登记表只允许 GAME_OBSERVATION，目前为空且没有对外写入接口。事实来源和版本必须匹配其快照，数据库触发器禁止将 SIMULATOR 混入官网快照。历史版本 current_verified 固定为 0，阶段 executable 固定为 0。

game_version 的当前记录代表网页快照的版本上下文，不冒充游戏构建号。实际 version_number 保持 NULL。正式版 / QQ 魔域等渠道来自原文；网页未显示的发布时间为 NULL。2010 URL 日期只存 url_date_hint，不能替代页面发布时间，也不能据此推断副本首次上线日期。

每条 fact_evidence 保留 URL（通过快照来源关联）、来源发布时间、实际采集时间、原文片段、CSS 定位、快照 SHA、原始值、JSON 规范值、版本与验证状态。已抽取状态为 OFFICIAL_PAGE_EXTRACTED，表示对应网页文本证据可核对；**并不表示当前官服事实已验证**。缺失字段为 UNKNOWN，规范值为 null；“未检测到”仅指指定页面与本提取器范围。

旧知识占位接口 `/api/knowledge/{kind}` 保持兼容，新增正式知识应查询下面的复数接口，不能混用旧命名空间与原模拟数据。累计模拟收益仍只由真实副本拾取与结算事件生成。

## 只读 API

```text
GET /api/knowledge/dungeons
GET /api/knowledge/dungeons/alama
GET /api/knowledge/dungeons/alama/stages
GET /api/knowledge/dungeons/alama/bosses
GET /api/knowledge/dungeons/alama/rewards
GET /api/knowledge/dungeons/alama/mechanics
GET /api/knowledge/sources
GET /api/knowledge/conflicts
GET /api/knowledge/snapshots/{id}
```

事实与实体返回 OFFICIAL_WEB、version_id、验证状态及 facts 证据列表；sources 返回发布时间、抓取时间、尝试记录、快照和数量。快照仅以附件 octet-stream 下载，不执行官网 HTML 脚本。`backend/knowledge_reader.py` 为 Agent 扩展提供只读客户端，仅允许指定 GET 查询，不生成 Decision，不调用世界动作。

`/api/agent/status` 标记 environment=SIMULATOR、knowledge_mode=READ_ONLY、official_execution_enabled=false。控制台显示 OBSERVATION 未启用。知识资料与模拟器数值并排说明，但不会互相补全。

## 数据空缺与 V1.2 建议

官网已列出名称、准入条件、队伍限制、入口、开放时段、阶段首领和物品清单，以及部分页面的项链豁免说明。实际地图网格、障碍、首领技能/生命/攻击/防御、机关触发、掉落数量/概率、进入消耗、每日次数、实际游戏构建号和首次开放日期仍未知。物品名中的“+1”“+2”“30星”是名字的一部分，不能解释成掉落件数或掉落率。神 O 与神兽碎片的历史命名不自动合并。

V1.2 应先通过授权测试环境采集带授权记录、时间戳、截图与构建号的 GAME_OBSERVATION，人工核对坐标、阶段、机关和技能时序，记录采样次数与不确定性，再选择明确版本建立独立数字孪生。未确认字段保留未知分布；官方历史物品名不能直接替代 V1.0 模拟收益。用持有真值的评估器检验视觉、地图和机制一致性，逐项通过后才考虑在授权环境启用动作适配器。仍不连接未授权的官服自动操作。
